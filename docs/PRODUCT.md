# Education 项目产品文档

## 项目概述

Education 是一个教育类项目，包含化学和数学两个学科的网页应用，旨在为学生提供知识学习、练习题库和智能组卷等功能。

## 产品模块

### 1. 化学模块 (Chem Web)

#### 1.1 产品定位
独立版化学连接学习网页应用，面向内部学习、评审和题库整理。

#### 1.2 核心功能
- **化学知识网络**：焦点节点、关联知识点、总览缩放和滚轮缩放
- **课程学习**：折叠式课程内容、相关知识点跳转、相关课程跳转
- **练习题库**：选择、判断、填空、简答、计算、实验、推断、流程题等题型
- **智能组卷**：自定义知识点权重、题型结构和总分分配
- **PDF 导出**：通过浏览器打印生成试卷、答题卡和答案解析
- **本地题图**：实验装置图、推断关系图、工艺流程图等
- **学习档案**：本地记录答题数、正确率、错题和课程完成状态
- **每日练**：按薄弱模块、错题模块和基础保分题生成练习
- **阶段报告**：汇总正确率、薄弱模块和复习入口
- **内部参考资料**：缓存高考化学 PDF 原卷/解析，用于后续拆题和校对

#### 1.3 用户场景
- 学生：进行化学知识学习、练习题目、查看学习报告
- 教师：整理题库、生成试卷、评估学生学习情况
- 内部人员：评审和校对题目内容

### 2. 数学模块 (Math)

#### 2.1 产品定位
数学知识展示和练习网页应用（开发中）。

#### 2.2 规划功能
- 数学知识展示
- 数学题目练习
- 数学学习资源

## 用户角色

1. **学生用户**：主要使用学习、练习、测试功能
2. **教师用户**：使用题库管理、试卷生成功能
3. **内部管理员**：负责内容审核、数据维护

## 产品特点

1. **本地化部署**：支持本地运行，无需联网
2. **数据安全**：学习记录保存在本地浏览器
3. **多题型支持**：覆盖化学学科多种题型
4. **智能推荐**：基于学习情况的个性化练习推荐
5. **PDF导出**：支持生成标准试卷格式

## 技术栈

- 前端：HTML5 + CSS3 + JavaScript
- 后端：Node.js
- 数据库：MySQL（发布版本）
- 数据存储：JSON文件（开发版本）
